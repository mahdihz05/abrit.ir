# AbrIT Corporate Website & CMS

Monorepo for the multilingual AbrIT public website and its Django-based CMS.

## Applications

- `backend/`: Django 5.2 LTS, Django REST Framework, CMS and public API.
- `frontend/`: Next.js 16 App Router public website.
- `docs/`: architecture, delivery checklist and operating guides.
- `scripts/`: repeatable local and hosting tasks.

The implementation status is tracked in `docs/IMPLEMENTATION_CHECKLIST.md`. No production deployment is performed without explicit approval.
